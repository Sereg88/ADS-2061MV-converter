# bin2csv — конвертер осциллограмм AKTAKOM / АКИП ADS-2061M

Скрипт [`bin2csv.py`](bin2csv.py) читает «сырые» файлы осциллографа формата `.bin`
(проприетарный формат, магия `SPBS01e\0`) и сохраняет их в **CSV** (калиброванные
значения) и **PNG** (построенный график). Работает **без сторонних библиотек**
(numpy/matplotlib не нужны) — только стандартная библиотека Python.

---

## Возможности

- Декодирование файлов `.bin` прибора ADS-2061M (и совместимых).
- Калибровка по времени и напряжению под конкретную развёртку (В/дел, время/дел).
- Экспорт в CSV: `index; time_ms; code; volts`.
- Построение графика в PNG (автомасштаб, сетка, нулевая линия).
- GUI-форма с выбором файла и полей параметров + дамп заголовка и гистограмма кодов.
- Пакетный (CLI) режим для прогона нескольких файлов.
- Защита от перезаписи: существующие выходные файлы не затираются.

---

## Требования

- **Python 3** (проверено на 3.15; подойдёт любой 3.x).
- Для GUI — модуль `tkinter` (входит в стандартную установку Python для Windows).
  Проверка: `python -c "import tkinter; print(tkinter.TkVersion)"`.
- Внешние зависимости отсутствуют.

## Быстрый старт

### GUI (форма)

```
python bin2csv.py
```

Откроется окно с полями. Порядок работы:

1. **Файл осциллограммы (.bin)** — нажмите «Обзор…» и выберите файл (или впишите путь).
2. Кнопка **«Прочитать заголовок»** — покажет модель, канал, все поля заголовка и
   гистограмму кодов payload (по ней видно, «схлопнут» ли сигнал в 1–2 значения).
3. Заполните **калибровку** — значения, которые вы видите на экране прибора
   (В/дел, Время/дел, отсчётов на деление, смещение).
4. При необходимости поправьте **формат данных** (смещение, байт/отсчёт, знаковость…).
5. Нажмите **«Декодировать в CSV + PNG»**. В журнале появятся `dt`, В/код, диапазон
   напряжений, топ кодов, первые значения и пути к созданным файлам.

### CLI (без GUI)

```
python bin2csv.py <файл.bin> <В/дел> <время/дел> [отсч/дел] [смещ/дел]
```

Примеры:

```
python bin2csv.py 20090511_233154.bin "2 V" "1 ms" 50 0
python bin2csv.py 20090511_231914.bin 2 1ms
```

Значения можно писать с единицами (`"2 V"`, `"1 ms"`, `"500 мВ"`) или просто числом.
Единицы понимаются в латинице и кириллице (`V/мВ`, `ms/мс`, `us/мкс`, `ns/нс`).
По умолчанию `отсч/дел = 50`, `смещ/дел = 0`.

## Описание GUI-полей

| Поле | Смысл | По умолчанию |
|---|---|---|
| Файл .bin | входной файл прибора | — |
| Вольт/деление | вертикальный масштаб с экрана прибора | `2 V` |
| Время/деление | горизонтальный масштаб с экрана прибора | `1 ms` |
| Отсчётов на деление | сколько отсчётов файла приходится на одно деление по горизонтали | `50` |
| Смещение, делений (офсет) | вертикальный офсет в делениях (0 = линия в центре) | `0` |
| Множитель щупа (x) | множитель для щупа (1x/10x/…) | `1` |
| Смещение данных (hex/dec) | байтовое смещение начала отсчётов в файле | `0x71` |
| Байт/отсчёт | разрядность: 1 (int8) или 2 (int16 LE) | `1` |
| Отсчётов (0 = авто) | ограничить число отсчётов; 0 — взять всё | `0` |
| знаковый | трактовать значения как знаковые | вкл. |
| строить PNG | строить ли график | вкл. |
| Имя выходных файлов | базовое имя без расширения (автоматически = `<вход>_decoded`) | авто |

## Формат .bin (вскрыт по эталону-меандру)

```
0x00  "SPBS01e\0"            магия (8 байт)
0x0A  "ADS-2061M1942004\0"   модель прибора (ASCII, до 0x00)
0x35  ";CH1" / ";CH2"        канал
0x28, 0x29, 0x59             служебные настройки (в байтах)
0x49, 0x4D  int32 = 1000     число отсчётов
0x61, 0x6D  float            служебные float (напр. 20.0)
0x65, 0x69  float            для меандра 1000.0, для шума 0.0 (вероятно, частота)
0x71        ...              полезная нагрузка: отсчёты (по умолчанию 1 байт/отсчёт)
```

Размер файла = `0x71` (113 байт заголовка) + `число_отсчётов × байт/отсчёт`.

**Ключевые соглашения:**

- **1 код = 0.1 деления** по вертикали. При 2 В/дел: **1 код = 0.2 В**.
- Значения **знаковые**: код `255 = −1`, `254 = −2` и т.д. (всплески/звон ниже нуля).
- Меандр 1 кГц дал период 50 отсчётов → **dt = 20 мкс/отсчёт** (запись 1000 отсчётов = 20 мс).

## Формулы калибровки

```
dt (мкс/отсчёт)  = (Время/деление) / (отсчётов на деление) × 1e6

volts (В)        = (code − смещение_дел × 10) × 0.1 × (В/дел) × (множитель щупа)
```

Проверка на эталоне (`2 V`, `1 ms`, `50 отсч/дел`, щуп ×1):

- `dt = 1 ms / 50 = 20 мкс`;
- `0.2 В/код`; уровни меандра: код 0 → 0 В, код 25 → **5.0 В** ✓.

## Выходные файлы

### CSV

Разделитель — `;`. В начале строки-комментарии (`#`) со всеми входными параметрами
и дампом заголовка, затем шапка и данные:

```
# index;time_ms;code;volts
0;0.0000;0;0.000
1;0.0200;0;0.000
...
```

- `index` — номер отсчёта;
- `time_ms` — время в миллисекундах (шаг = `dt`);
- `code` — сырой код (уже с учётом знака, `255 → −1`);
- `volts` — напряжение в вольтах.

### PNG

Черно-белый график 1000×340 (градации серого, без внешних библиотек): сигнал
рисуется ступенькой, есть координатная сетка и утолщённая нулевая линия.
Вертикальный масштаб выбирается автоматически по данным.

### Правило имён и защита от перезаписи

- Базовое имя по умолчанию — `<имя_входа>_decoded`, кладётся рядом с входным файлом.
- Имя выходных файлов автоматически следует за выбранным входным файлом.
- **Если файл с таким именем уже есть, он не перезаписывается** — создаётся новый
  с суффиксом `_2`, `_3`, … (в GUI это отмечается в журнале).

## Использование как модуля

```python
from bin2csv import convert

res = convert("20090511_233154.bin", vdiv=2.0, tdiv=1e-3, spd=50.0,
              offset_div=0.0, probe=1.0, make_png=True)

print(res["dt_us"], res["volts_per_code"])   # 20.0  0.2
print(res["csv"], res["png"])                # пути к созданным файлам
print(res["vmin"], res["vmax"])              # диапазон напряжений, В
```

Ключевые параметры `convert`:

| Параметр | По умолчанию | Назначение |
|---|---|---|
| `path` | — | входной `.bin` |
| `vdiv`, `tdiv` | — | В/дел и секунды/дел (числа) |
| `spd` | `50` | отсчётов на деление |
| `offset_div` | `0` | смещение нуля в делениях |
| `out_base` | авто | базовое имя вывода (без расширения) |
| `data_offset` | `0x71` | смещение начала данных |
| `bps` | `1` | байт/отсчёт |
| `count` | `0` | 0 = все отсчёты |
| `signed` | `True` | знаковые значения |
| `probe` | `1.0` | множитель щупа |
| `make_png` | `True` | строить график |

## Частые ситуации

- **В гистограмме кодов только `0` и `1`** — сигнал занимает ~0.1 деления, т.е. снят
  при слишком грубом В/дел: СКЗ сигнала меньше одного шага квантования. Увеличьте
  чувствительность на приборе (меньше В/дел) и запишите заново.
- **Напряжения завышены в 10 раз** — проверьте «множитель щупа»: при щупе 1:1 он
  должен быть `1`, при 1:10 — `10`.
- **Магия «НЕ совпала»** — файл не от этого прибора либо это не осциллограмма.
- **Ошибка «не выделено ни одного отсчёта»** — проверьте «смещение данных» (`0x71`).
- **GUI не открывается** — запустите в CLI-режиме либо проверьте наличие `tkinter`.

---

## Ограничения

- Разбор проверен на ADS-2061M (серийник 1942004). У других прошивок/моделей
  смещение данных и разрядность могут отличаться — для этого в форме есть поля
  «смещение данных», «байт/отсчёт» и «знаковый».
- Прибор штатно пишет 1000 отсчётов; предполагается, что запись короче экрана либо
  экран делится на 20 делений при 1 мс/дел (уточняется по скриншоту кадра).
